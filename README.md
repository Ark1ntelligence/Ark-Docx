# Ark-Docx · 公文排版技能

将 PDF / Word / PPT / 图片 / 扫描件材料一键排版为符合公司《公文排版规范》的 Word 文档（.docx），支持按要点起草、批量排版、低级错误检查与修改对比报告。面向豆包桌面版「本地电脑」模式使用。

## 功能特性

- **多格式输入**：PDF / Word / PPT / 图片 / 扫描件（OCR）
- **一键流水线**：`pipeline.py` 将「提取 → 审稿 → 生成 → 验证 → lint」合并为单进程调用，单次调用大幅省时
- **规范排版**：A4、页边距上 3.7 / 下 3.5 / 左 2.8 / 右 2.6 cm、每页 22 行 × 28 字、页码"— 1 —"（首页无页码）
- **标准字体**：主标题 2 号方正小标宋、正文三号仿宋_GB2312、固定行距 28 磅、首行缩进 2 字符
- **丰富要素**：括号注释（楷体四号）、附件正文页、正文插图、国标全框线表格、"一是/二是/三是"自动加粗
- **质量保障**：自动格式验证 + 低级错误检查（标点 / 空格 / 编号 / 英文 / 重复字 / 日期）
- **修改对比**：排版后自动生成对比报告，逐处标注删除 / 新增 / 改写并附「原因」说明
- **起草与批量**：按要点直接起草公文正文、一次批量排版多份材料
- **绿色便携版**：技能包内置 Python 运行时（`runtime\`），新电脑解压即用、免装 Python、免联网下载依赖

## 快速开始

> 安装一次即可，之后每次排版只需把文件交给豆包、说一句话。以当前版本（v0.3.1）为例，两种部署方式任选其一：

**方式 A · 绿色便携版（推荐，免装 Python / 免联网）**

1. 解压 `releases/Ark_Docx_v0.3_portable.zip`，得到 `Ark_Docx_v0.3` 文件夹
2. 双击 `run.bat`：自动自检运行时 + 安装公文字体（已装自动跳过）
3. 把整个文件夹复制到豆包技能目录（如 `C:\Users\你的用户名\Doubao\skills\ark_docx_v0.3`）
4. 重启豆包桌面版，进入「本地电脑」模式即可使用

**方式 B · 联网一键安装**

1. **安装字体**：运行 `fonts\install_fonts.bat`（安装方正小标宋、仿宋_GB2312、楷体_GB2312）
2. **安装环境**：运行 `installer\install.bat`（自动安装 Python + 依赖 + 复制技能 + 字体）
3. **重启豆包**：完全退出后重新打开，使新技能与依赖生效
4. **使用**：进入「本地电脑」模式，发送文件并说"用公文排版技能，把这个文件排成公文格式"

## 目录结构

```
Ark-Docx/
├── README.md            # 项目说明（本文件）
├── LICENSE              # 许可证
├── CHANGELOG.md         # 版本更新日志（Keep a Changelog 规范）
├── VERSIONING.md        # 版本管理规范
├── .gitignore
├── example/             # 使用示例（含实际排版样例）
│   └── _pre_release_backup/  # 发布前备份的原始含业务文件（敏感，勿提交，确认后删除）
└── releases/            # 版本分发包归档（每个版本一个独立目录）
    ├── Ark_Docx_v0.1/   # v0.1 分发包（历史版本）
    ├── Ark_Docx_v0.2.zip # v0.2 分发包归档（历史版本）
    ├── Ark_Docx_v0.3/   # v0.3 分发包（当前版本，含 runtime\ 与 run.bat）
    └── Ark_Docx_v0.3_portable.zip # 绿色便携版分发包（当前版本，自带 Python 运行时）
```

每个版本独立归档，互不影响；最新使用以版本号最大的分发包为准。绿色便携版可直接解压分发，无需目标电脑安装 Python。版本管理规范见根目录 `VERSIONING.md`。
